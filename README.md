## Описание задачи

В данной работе решается задача бинарной классификации: по характеристикам заемщика и параметрам кредита необходимо предсказать, будет ли одобрен кредит.

Для этого используется датасет с платформы Kaggle, содержащий информацию о доходах клиента, кредитной истории, уровне долговой нагрузки, а также других социально-экономических признаках.

Качество моделей оценивается с помощью метрик accuracy, precision, recall, F1-score и ROC-AUC, при этом основное внимание уделяется F1-score и ROC-AUC как более информативным показателям для задачи классификации с возможным дисбалансом классов.

**Задача:** Классификация

**Датасет:** Financial Risk for Loan Approval (https://www.kaggle.com/datasets/lorenzozoppelletto/financial-risk-for-loan-approval?resource=download&select=Loan.csv)

**Целевая метрика:** [F1 и ROC-AUC]
